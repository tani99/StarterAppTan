# Starter App

A modern React Native fashion app built with Expo and Firebase.

## 🚀 Quick Start

### Prerequisites
- Node.js >= 20.0.0
- Firebase project (for authentication)

### Initial Setup

1. **Clone and install dependencies:**
```bash
git clone https://github.com/tani99/StarterAppTan.git
cd StarterAppTan
npm install
```

2. **Set up Firebase configuration:**
```bash
# Copy the example config file
cp app/config/firebase.ts.example app/config/firebase.ts
```

Then edit `app/config/firebase.ts` with your Firebase project credentials.
See detailed instructions in [app/config/firebase-setup.md](app/config/firebase-setup.md)

3. **Add Platform-Specific Firebase Configuration Files:**

These files contain API keys and CANNOT be committed to the repository. You must add them yourself.

**For iOS:**
1. Generate the iOS folder: `npx expo prebuild --platform ios`
   - This command will generate the `ios/` directory but will likely fail with a missing `GoogleService-Info.plist` file error
2. In Firebase Console, go to Project Settings → Your apps
3. Add an iOS app (or select existing) with bundle identifier: `com.starterapptan`
4. Download `GoogleService-Info.plist`
5. Place it at: `ios/GoogleService-Info.plist`
   - DO NOT commit this file - it's already in `.gitignore`
6. Rerun the prebuild command: `npx expo prebuild --platform ios`
7. **⚠️ CRITICAL: Update Podfile**
   
   The auto-generated Podfile requires extensive modifications to work with Firebase and React Native 0.79+. After running prebuild:
   
```bash
# Copy the working Podfile configuration
cp Podfile.reference ios/Podfile
```

8. Install iOS dependencies:
```bash
cd ios
pod install
cd ..
```

**For Android:**
1. Generate the Android folder: `npx expo prebuild --platform android`
   - This command will generate the `android/app/` directory but will likely fail with a missing `google-services.json` file error
2. In Firebase Console, go to Project Settings → Your apps
3. Add an Android app (or select existing) with package name: `com.starterapptan`
4. Download `google-services.json`
5. Place it at: `android/app/google-services.json`
   - DO NOT commit this file - it's already in `.gitignore`
6. Rerun the prebuild command: `npx expo prebuild --platform android`

> **Note:** The `ios/` and `android/` directories are generated by Expo's prebuild process and contain native code. They may not exist in a fresh clone of the repository.

4. **Start the development server:**
```bash
npm run start
```

## 🏃 Running the App

### Android

After completing the setup steps above, you can run the Android app:

```bash
npm run android
```

### iOS

#### Configure Signing & Capabilities in Xcode

1. Open the project in Xcode:

```bash
open ios/StarterAppTan.xcworkspace
```

2. In Xcode:
   - Select the **StarterAppTan** project in the navigator
   - Select the **StarterAppTan** target
   - Go to **Signing & Capabilities** tab
   
3. Under **Signing**:
   - Choose your **Team** (Apple Developer account)
   - Ensure **"Automatically manage signing"** is checked
   - Verify the **Bundle Identifier** matches: `your-firestore-bundle-identifier`

4. Under **Capabilities**, ensure these are added:
   - Sign in with Apple (if using Apple authentication)
   - Push Notifications (if needed)

> **Note:** For device testing, you need an active Apple Developer account (free or paid).

**Don't have an Apple Developer account?**
- For testing on your own device: You can use a free Apple Developer account (no cost, limited to personal device testing)
- For App Store distribution: You need a paid Apple Developer Program membership ($99/year)
- [Set up your Apple Developer account](https://developer.apple.com/programs/)

#### Build Options

**For iOS Simulator:**
```bash
npm run build:ios:sim
```

**For iOS Device (Development):**
```bash
npm run build:ios:dev
```

After the build completes, you can run the app:
```bash
npm run ios
```

Or open `ios/StarterAppTan.xcworkspace` in Xcode and run directly.

#### Troubleshooting iOS
- **"Module not found" errors:** Make sure you copied the reference Podfile and ran `pod install`
- **Signing errors:** Ensure your Apple Developer account is properly configured in Xcode
- **Build failures after prebuild:** Always copy `docs/Podfile.reference` to `ios/Podfile` and re-run `pod install`
